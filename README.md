# Team Workspace

A full-stack web application for managing teams, projects and tasks.

## Tech Stack

- Vue.js
- TypeScript / JavaScript
- Java + Spring Boot
- REST API
- PostgreSQL
- JWT Authentication
- Docker / Docker Compose
- Git / GitHub

## Planned Features

- User registration and login
- Team management
- Project management
- Task creation and assignment
- Task status and priorities
- Role-based access

## Status

Project is currently under development.
